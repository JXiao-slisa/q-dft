> 版本: V2.0 | 状态: active

## 1. 三层迭代循环

```
┌────────────────────────────────────────────────────────────────┐
│ ③ 模式间迭代 (Mode-level)                                       │
│    快速模式(Quick) → 正常模式(Normal) → 扩展模式(Advanced)      │
│    ┌──────────────────────────────────────────────────────┐   │
│    │ ② 批次间迭代 (Batch-level)                            │   │
│    │    Batch1 → Batch2 → Batch3 → Batch4 → Batch5         │   │
│    │    不同规模/层级的科学探索问题                         │   │
│    │    ┌──────────────────────────────────────────────┐   │   │
│    │    │ ① 批次内迭代 (Intra-batch)                    │   │   │
│    │    │    本批次内部：计算→审阅→检索→修正→重跑        │   │   │
│    │    │    (不跨出本批次)                              │   │   │
│    │    └──────────────────────────────────────────────┘   │   │
│    └──────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────────┘
```

### 各层级触发条件

| 层级 | 触发 | 出口 |
|------|------|------|
| **批次内迭代** | 数据异常、统计不严谨、审稿人低/中严重度问题 | 修正后继续本批次 |
| **批次间迭代** | 本批次目标达成；审稿结论"推进" | 设计下一批次 |
| **模式间迭代** | 快速模式验证有效 → 正常模式完整统计 → 扩展模式新发现 | 模式升级 |

## 2. 审稿人机制（Reviewer Agent）

每个批次/节点完成后自动触发：

```
批次结果
   │
   ▼
① 审稿人 Agent 审阅（LLM 学术审稿）
   │  列出问题/质疑 + 严重程度
   ▼
② 联网检索确认（关键科学点）
   │  检索学术文献/数据
   ▼
③ 外部建议整合（用户/审稿建议）
   │
   ▼
④ 决策判定：重做 / 修正后推进 / 直接推进
   │
   ▼
⑤ 台账记录（JSONL 可追溯）
   │
   ▼
⑥ 知识入库 + 设计下一节点
```

### 台账（Ledger）可追溯

所有节点记录在 `results/<project>/rsi_ledger.jsonl`：
- 时间戳、模式、批次、阶段、决策、理由
- 内部 RSI 结论与外部建议的整合过程
- 完全可追溯（append-only）

## 3. 四类科学报告制度

每个批次产出四类文档：

| 报告 | 内容 | 文件 |
|------|------|------|
| **实验报告** | 计算参数、文件清单、优化日志、原始数据 | `experiment_*.md` |
| **学术报告** | 科学结果、物理意义、图表、讨论 | `academic_*.md` |
| **检索报告** | 文献检索记录、与文献对比、引用 | `literature_*.md` |
| **分析报告** | 审阅结论、质疑响应、重做分析、决策 | `analysis_*.md` |
| **汇总结论** | 四类报告结论简明汇总 | `conclusions_*.md` |

## 4. 质量标准（审稿人关注点）

1. **统计严谨**：独立样本数 ≥ 10，去冗余，R² 基于独立样本
2. **物理图像**：吸附能 + 过渡态 + 溶剂化校正
3. **scaling law**：基于去冗余数据的斜率/截距/R²
4. **活性火山图**：过电位 vs 描述符（真正火山型）
5. **结构记录**：每个中间体的优化前后对比
6. **MLIP 验证**：与 DFT 基准对比（误差 < 0.2 eV）
7. **报告规范**：四类报告 + 可视化 + 台账
